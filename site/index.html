04 / ABOUT

关于我 About

深耕自动化测试与效能基础设施

我是 yanpei.fan，一名游戏测试开发工程师，从业 10 年+。与传统的"点点点"测试不同，我的工作是用工程化手段解决测试难题、提升团队研发效能。

我主导了自动化测试体系在 10+ 个游戏项目中的规划与落地——与团队共同设计的 CenturyBox 框架统一了配置表 / 接口 / UI 三大测试领域，接入 CI/CD 全自动回归后，全量回归由 3 天缩短至 60 分钟，回归人力节省 50%。同时从 0 到 1 建设了 Code Dye 覆盖率工具链、LLM Gate AI 网关、SkillHub 技能平台等多项效能基础设施。

我的技术栈以 Python 为核心，擅长测试框架设计、用例工程化、FastAPI 后端开发、Protobuf/二进制协议解析及游戏测试工具链建设，前端具备 React + TypeScript 实战能力，并配套完整的文档体系与团队培训推广经验。

在 AI 领域，我专注于 LLM 应用工程化——自建企业级 AI 网关（LLM Gate）与 AI 技能平台（SkillHub），将 AI 能力落地到招聘审核（HR Campus Recruit）、LQA 截图自动提 Bug 等真实业务并上线使用；日常使用 AI 编码助手（Agent / Claude Code 等）提效开发。

我享受构建工具的过程——识别团队痛点，设计架构，写代码，看到它真正被同事们日常使用。这种让测试更简单更高效的成就感，是我持续精进的原动力。
