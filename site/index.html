关于我

深耕自动化测试与效能基础设施

我是 yanpei.fan，一名测试开发工程师。与传统的"点点点"测试不同，我的工作是用工程化手段解决测试难题、提升团队研发效能。

过去几年，我参与搭建了团队的自动化测试框架 CenturyBox——统一了配置表测试、接口测试和 UI 测试三大领域，覆盖 10+ 各类型游戏。同时参与建设了 SkillHub AI 能力平台、LLM Gate 统一网关、Code Dye 代码覆盖率工具、飞书 SDK 等一系列效能基础设施。

我的技术栈以 Python 为核心，擅长 FastAPI 后端开发、测试框架设计、Protobuf/二进制协议解析、以及游戏行业测试工具链的搭建。前端方面具备 React + TypeScript 的实战能力。

在 AI 领域，我深入理解 Transformer 架构、RAG 检索增强生成、Attention 机制以及 LLM API 接口设计。日常工作中高频使用 Agent 模式构建复杂自动化工作流，熟悉各大模型的能力边界与适配方案，善于将 AI 能力工程化落地到实际业务场景。

我享受构建工具的过程——识别团队痛点，设计架构，写代码，看到它真正被同事们日常使用。这种让测试更简单更高效的成就感，是我持续精进的原动力。
